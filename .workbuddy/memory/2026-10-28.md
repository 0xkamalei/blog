# 2026-10-28

## 博客新增「知识」板块（架构图 / 独立 HTML 页面托管）

- 导航改为三节点：文章(`/`) · 知识(`/knowledge/`) · 关于(https://leix.dev)。
  `Layout.astro` 新增 `wide` prop（`body.wide` → `--content-max: 1440px`）与 `head` 具名插槽。
- 内容约定：`src/knowledge/*.html` 直接丢文件即可发布到 `/knowledge/<文件名>/`，
  可选侧车 `<slug>.meta.json` 覆盖 title/description/tags/date/order，`_` 开头忽略。
- 渲染关键技术：`src/lib/knowledge.ts` 构建期把 HTML 拆成 `<style>` + body，
  输出**声明式 Shadow DOM**（`<template shadowrootmode="open">`）嵌进页面，
  源页面的 `*{margin:0}` / `body{background:#020617}` 完全隔离，不影响博客主题，且服务端直出无 JS。
  源码里的 `html`/`body` 规则会被提升为 `.kb-root` 以保留背景/字体/内边距（过滤掉 min-height/height）。
- 配套：`scripts/add-knowledge.ts`（`bun run kb:add <file> [--slug --tags --date]`）自动复制并抽取标题/摘要。
- 首个收录：`outbox-end-to-end-sequenced.html`（Transactional Outbox 端到端架构图，深色 1300px 宽 SVG，靠容器横向滚动）。
- 已知限制：Shadow DOM 内 `<script>` 不执行；如需交互要走 Astro 组件或手动 attachShadow。
- 构建验证通过（33 页），dev server 跑在 4321 用于目检。
